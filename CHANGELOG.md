# Changelog

## v0.6.0-beta

Initial public beta.

- Party quest overview for 2–5 players: progress per objective, level, XP and rested XP
- RestedXP integration (optional): show only quests from the current guide steps, with look-ahead and guide order
- Quest sharing: auto-share, shift-click to share or request a share (with feedback and automatic retry), "share missing quests"
- Missing quest hints with quest giver info (if Questie is installed)
- "Who needs this?" loot upgrade hints, compared against each player's own gear
- Hearthstone cooldown and bind location sync
- Ready? check: bag space, durability and hearthstone for everyone
- Filters: group by zone, only differences, hide completed / class / profession / camping quests, hide by Alt-click
- Hidden in raids by default (option: show own raid group)
- Minimap addon menu entry
- Resizable window: drag the corner for quest name width and number of rows
- Click a quest to expand its objectives into single rows
- Optional RestedXP target macro with attack ping (`/pace macro`)
- Guide filter follows the whole party: steps of members behind or ahead of you stay visible
